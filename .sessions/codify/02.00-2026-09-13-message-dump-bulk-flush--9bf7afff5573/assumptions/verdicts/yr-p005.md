In `tests/qa/test_qap_ms001.py`, the TC-100 collapsed-format gate fails if a `turn_NNN.json` or `index.txt` appears anywhere under the session directory before the flush — not only if a `.log` file appears.

## What it actually does
The gate's negative checks are not `.log`-scoped; they reject the documented layout too.

- Pre-flush, while `log_artifacts(str(dump))` (recursive `*.log` search, `harness.py:127-133`) is empty, the gate takes `listing(sid_dir)` — `sorted(os.listdir(path))` — and asserts `snapshot == []` (test_qap_ms001.py:185-192). That is a universal absence check over the session directory's direct entries: a `turn_NNN.json`, an `index.txt`, or any other entry fails it immediately.
- A file nested deeper than the session directory's top level is not seen by that non-recursive `os.listdir` snapshot, but the gate still fails on it after the run: `assert listing(sid_dir) == [f"{COLLAPSED}.log"]` fails because the intermediate directory is itself a direct entry (test_qap_ms001.py:205-207), and `assert not [p for p in rglob_files(str(dump)) if not p.endswith(".log")]` fails on any non-`.log` file at any depth (test_qap_ms001.py:208-210). `rglob_files` is a recursive `os.walk` (`harness.py:118-124`). The test removes nothing, so a file written during the run is still present for those assertions.
- A `.log` appearing is not itself rejected — it is the expected artifact (`assert listing(sid_dir) == [f"{COLLAPSED}.log"]`, test_qap_ms001.py:205-207). What it does is disable the pre-flush snapshot for that iteration via `if not has_artifact`; the gate then fails only if no pre-flush snapshot was ever observable (`assert pre_flush_snapshots`, test_qap_ms001.py:193-196). So the contrast clause is accurate in its substantive sense: the failure set is broader than "a `.log` file appeared".

Boundary worth recording: a nested documented file that appeared and was removed again before the post-run assertions would escape — the pre-flush check is `os.listdir`, not recursive. Nothing in this test removes files, so that path is not exercised.
