## Claim
In `buster_ripper/dump.py`, the documented branch's writes are the only writes that run for a documented turn (no second writer runs).

## What it actually does
For `fmt == "documented"`, `dump_turn` calls only `_write_documented`, which writes `turn_000.json` or `turn_{N:03d}.diff` and appends the `index.txt` summary line. The collapsed artifact writer is never reached: `_append_record` is not called (so no `flush_all()` fires from the append path), and `_flush_state` returns immediately when `state.fmt == "documented"`, so a periodic `poll_flush`/`flush_all` writes nothing for that session. The only other side effects are the per-session directory `mkdir` in `_lookup_or_create_state` and `log.info` lines, not an artifact writer.
