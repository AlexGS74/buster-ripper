- **H1 — `set -u` abort on the unset case.** A default word exempts the reference from `nounset` (`lang:bash` member 186), so
  `${DUMP_DIR-…}` cannot abort where `${DUMP_DIR:-…}` did not. Confirmed: replay A rc=0.
- **H2 — `set -e` abort on line 36's false arm.** This is the increment's genuinely new state: before the fix, `-n "${DUMP_DIR}"`
  could not be false from the environment, so `[[ … ]] && …` had never returned 1 on that line under `errexit`. The failing
  command is not the one following the final `&&`, so errexit is exempt (member 188) — and the peers at lines 37/38 already prove
  the shape live every default run. Confirmed: replays B, D, E all rc=0.
- **H3 — the fix moves the *unset* path too** (the exact wrong outcome the verification profile names: ordinary documented runs
  silently stop dumping). Denied structurally (single-line, single-hunk diff; line 36's guard condition untouched) and by witness:
  replay A still carries exactly one `--dump-dir <HOME>/mllm/prompt-diffs`.
- **H4 — newly reachable `EXTRA_FLAGS` zero-word arm.** With every guard false, line 46's unquoted expansion yields zero words;
  the variable is set-but-empty, so `set -u` cannot fire. Confirmed: replay E emits only the trio, rc=0.
- **H5 — `${HOME}` dereference (observation C4).** Not worsened: it is *shrunk*. Replay G (`HOME` unset + `DUMP_DIR=""`) now runs
  clean because the default word is never expanded; replay H (`HOME` unset + `DUMP_DIR` unset) still aborts at line 28, exactly as
  on the pre-fix bytes. Pre-existing premise, unchanged, and the composition records it as an observation, not a finding.

  sets are unchanged) and the new witness. Nothing under `buster_ripper/` reads the script; `tests/qa/harness.py` builds argv itself
